How it works

Three steps. No design debt.

Docs sits between AI output and the document you send. Convert is free. Brand memory is the product.

  1. 01

    Write Markdown

    Draft in the editor or paste from Claude, Cursor, or ChatGPT. Headings, lists, code — kept as structure, not spaghetti HTML.

  2. 02

    Apply the Brand Layer

    Logo, colors, fonts, header and footer — set once. Every export inherits your identity without another design pass.

  3. 03

    Export PDF

    Print-ready pages with soft paper spacing. Download for humans, or return a link when an agent calls Docs via MCP.

Features

Intention over automation theater

Rendering Markdown is a commodity. Persistent brand + agent delivery is the wedge. Docs owns the last mile between AI and a document you can send.

  • MD → PDF that prints

    Clean typography, soft paper margins, and page breaks that respect your headings — not a browser print dialog in a trench coat.

  • JetBrains Mono for source

    The editor speaks Markdown in mono. The PDF speaks Inter. Two fonts, one calm craft language across the Dynamogic suite.

  • Brand Layer ready

    Connect logo, colors, and letterhead once. Every brief, proposal, and agent output ships looking like your company made it.

  • Built for agents

    MCP-friendly render path on the roadmap: agents return a view/download link so you never leave the chat to chase a PDF.

  • Free core convert

    Write and export forever at $0. Pro unlocks brand kits, templates, and higher limits — never a brick wall on Markdown → PDF.

  • Suite identity

    Same soft paper tokens as Brand Layer and BePro. Future home docs.dynamogic.com — charcoal calm, not purple sludge.
