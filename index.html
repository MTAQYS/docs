How it works

Three steps. No design debt.

  1. 01

    Write

    Draft or paste Markdown. Headings, lists, code — kept as structure.

  2. 02

    Brand

    Logo, colors, letterhead — set once. Every export inherits it.

  3. 03

    Export

    Print-ready PDF. Download for humans, or return a link for agents.

Features

Print-shop craft. Agent-ready.

  • MD → PDF that prints

    Quiet type, soft margins, page breaks that respect headings — not a browser print dialog.

  • Brand kit that sticks

    Logo, colors, letterhead once. Every brief and agent output ships looking like yours.

  • Built for agents

    MCP render path on the roadmap: agents return a view link so you never leave the chat.

  • Free core convert

    Write and export forever at $0. Pro unlocks brand kits and templates — never a brick wall.
